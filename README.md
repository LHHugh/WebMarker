# 柔光荧光笔

一款基于 Chrome Manifest V3 的网页文字标记扩展。左键拖动选择文字后，文字附近会出现浮动工具条，可添加低饱和背景色或彩色下划线。

## 功能

- 选择文字后自动显示标记工具，无需进入绘图模式
- 背景色与下划线两种样式
- 柔黄、柔绿、柔蓝、柔粉、柔紫、柔橙 6 种低饱和常规颜色
- 每处标记都会在网页右侧生成一个彩色小标签，悬停查看摘要，点击平滑跳转
- 按网址自动保存在浏览器本地，刷新页面后自动恢复
- 使用文本内容和上下文重新定位标记，兼容 VitePress 等 SPA 站点的站内跳转与正文重渲染
- 弹窗可撤销上一处标记或清空当前页面
- 已打开但尚未注入脚本的普通网页，会在打开扩展弹窗时自动补注入
- 不上传页面内容或标记数据

## 安装

1. 克隆本仓库，或点击 GitHub 的 **Code → Download ZIP** 并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择仓库根目录 `soft-marker-chrome-extension`。
5. 如果此前已经安装旧版，请在扩展卡片上点击“重新加载”，然后刷新已打开的网页一次。

## 使用

1. 在普通网页上按住鼠标左键拖动，选择需要标记的文字。
2. 松开鼠标，文字附近会显示浮动工具条。
3. 选择“背景色”或“下划线”，再点击一种颜色完成标记。
4. 标记完成后，网页右侧会出现同色小标签；悬停查看文字摘要，点击即可跳转到对应位置。
5. 若要移除局部标记，重新选中该文字，点击工具条中的“清除标记”。
6. 点击扩展图标，可设置默认样式、撤销上一处标记或清空当前页面。

## 权限说明

- `storage`：在本机保存默认样式和各页面的文字标记。
- `activeTab` 与 `scripting`：用户打开扩展弹窗时，为尚未注入脚本的当前普通网页补充加载标记工具。
- `http://*/*` 与 `https://*/*` 内容脚本：监听文本选择、显示浮动工具条并恢复已保存标记。

Chrome 自身页面、Chrome 网上应用店以及其他受保护页面禁止扩展注入，因此无法标记，这是浏览器的安全限制。若网页正文之后发生大幅修改、选中文字已不存在，对应旧标记会保留在本地但暂时无法显示。
